# [SFC] 파이널 판타지5 한글패치

슈퍼패미콤 **파이널 판타지5** 한글패치입니다. 슈퍼패미콤 실기에서 구동하는 것을 목표로 작업했습니다.

- 블로그 소개글: https://dwyn.tistory.com/
- 최신 버전 다운로드: [Releases](../../releases/latest)
- 버그 제보: [Issues → 버그 제보](../../issues/new/choose)
- 후원: https://litt.ly/dwyn

## 주요 작업 사항

1. 슈퍼패미콤 실기에서 구동되는 것을 목표로 한 한글패치입니다.
2. 파이널판타지 픽셀 리마스터의 번역을 참조했습니다.
3. 모든 대사, 아이템, 마법, 잡, 어빌리티, 메뉴와 전투 메뉴 전반의 텍스트를 번역했습니다.
4. 주인공 이름은 최초 입력 시 '바츠'로 자동 세팅됩니다. '확인' 버튼을 눌러 진행하면 됩니다.
5. 대사 폰트와 메뉴·전투 폰트 모두 갈무리 폰트를 사용했습니다.
6. 일본어판, 영문 번역판 세이브 파일(sav)도 호환되어 바로 사용할 수 있습니다.

**→ 엔딩까지 검수가 된 상태라, 이제는 망설이지 마시고 플레이해 주세요~!!**

### 알려진 문제

- 아이템 종류가 많을 때, 하드웨어 제약으로 아이템 이름이 제대로 출력되지 않는 경우가 있습니다. (발생 확률은 매우 낮습니다)

## 적용 방법

1. [Releases](../../releases/latest)에서 패치 파일을 받습니다.
2. 직접 가지고 계신 원본 ROM에 패치를 적용합니다.
   - 웹에서 적용: [ROM Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)
   - PC 프로그램: Delta Patcher, Floating IPS 등
3. 패치된 ROM을 에뮬레이터나 플래시카트로 실행합니다.

### 체크섬 확인

패치는 **헤더 없는 일본판 원본 ROM**(2,097,152바이트)에 적용해야 합니다.

| 구분 | CRC32 | MD5 | SHA1 |
|---|---|---|---|
| 원본 ROM (일본판) | `C1BC267D` | `D69B2115E17D1CF2CB3590D3F75FEBB9` | `E937B54FFF99838E2E853697E4F559359AA91FD6` |
| 패치 후 (v0.98, 3,145,728바이트) | `E78BE344` | `547D1AF5C5FA31E18F8710B84D1B8411` | `9177828499AA607AD0A8F4720CA1B9EEC522A736` |

- ROM Patcher JS에 ROM 파일을 넣으면 CRC32, MD5, SHA1이 바로 표시됩니다.
- 크기가 2,097,664바이트인 ROM은 512바이트 헤더가 붙은 파일이니, 헤더를 제거한 뒤 적용해 주세요.

> 이 저장소에는 패치 파일만 있습니다. ROM 파일이나 패치를 적용한 ROM은 배포하지 않으며, 요청에도 응하지 않습니다.
